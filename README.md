# MT论坛自动签到（用户脚本）

在 **MT论坛（https://bbs.binmt.cc/）** 每日自动签到。
兼容 **Tampermonkey（篡改猴）**、**Violentmonkey**、**Via 浏览器** 等脚本管理器。

作者：**YoyoAwA、DeepSeek**
项目地址：https://github.com/52Yoyo/mt-forum-auto-sign

## 功能

- **全站静默自动签到**：打开论坛任意页面，自动完成当日签到，不打扰浏览
- **签到页专属悬浮面板**：只有打开签到页 `k_misign-sign.html` 时才显示悬浮按钮与面板，其他页面保持干净
- **悬浮按钮可拖动**：长按「签」字按钮约 0.4 秒（手机有震动反馈）进入拖动模式，拖到任意位置松手即保存，下次打开仍在该位置；面板会跟随按钮位置智能显示（上方优先，空间不足自动换到下方）
- **恢复默认位置**：设置面板里一键恢复按钮初始位置（右下角）
- **定时签到**：可设置每天固定时间自动签到（页面保持打开时生效）
- **Material Design 3 原生视觉**：卡片式面板、丝滑动画过渡；浅色 / 深色主题**全自动跟随系统**切换，夜间模式柔和不刺眼
- **签到记录**：面板内查看最近 8 次签到结果，支持清空
- 同设备当天只签一次，不重复请求（localStorage 记录）

## 安装方法

### 电脑端（Tampermonkey / Violentmonkey）

1. 浏览器安装扩展：Tampermonkey（篡改猴）或 Violentmonkey
2. 点击工具栏扩展图标 → 「管理面板」→ 点击右上角 **「+」新建脚本**（会打开一个脚本编辑页）
3. **把 `mt-forum-auto-sign.user.js` 文件直接拖进浏览器页面内**，编辑器会自动载入文件内容
4. 按 `Ctrl+S` 保存
5. **回到管理面板，确认「MT论坛自动签到」开关是「已启用」**（新脚本默认启用，但偶尔会默认禁用）

> 也可以直接在浏览器中打开 `mt-forum-auto-sign.user.js` 文件（双击文件），扩展会自动弹出安装确认页，点「安装」即可。

### 手机端（Via 浏览器）

> ⚠️ **Via 浏览器脚本功能默认是关闭的，必须先开启！**

1. Via 浏览器 → 设置 → 通用 → **打开「脚本」开关**（第一次会提示安装脚本引擎，点击确认）
2. 打开脚本文件 `mt-forum-auto-sign.user.js`，Via 会识别 `==UserScript==` 头并提示安装
3. 确认 `@match` 覆盖 `https://bbs.binmt.cc/*`

## 使用方法

1. **先登录 MT 论坛账号**（脚本不处理登录，仅自动签到）
2. 任意打开论坛页面，约 1.2 秒后自动完成签到
3. 打开签到页 `https://bbs.binmt.cc/k_misign-sign.html`，右下角出现 MD3 悬浮按钮
4. 点击悬浮按钮展开面板：
   - 查看签到状态，手动签到 / 重试 / 去登录
   - **长按「签」字按钮**可拖动到任意位置，松手自动保存
   - **设置**：自动签到开关、定时签到开关 + 时间、结果提示开关、恢复按钮默认位置
   - **签到记录**：最近 8 次结果，可清空

## 设置说明

| 设置项 | 默认 | 说明 |
| --- | --- | --- |
| 自动签到 | 开 | 打开论坛任意页面自动签到 |
| 定时签到 | 关 | 每天指定时间自动签到（页面保持打开时生效） |
| 签到时间 | 08:00 | 定时签到的小时:分钟 |
| 结果提示 | 开 | 签到完成后弹出 Snackbar 提示 |
| 恢复按钮默认位置 | — | 按钮被拖动后，一键恢复右下角初始位置 |

主题自动跟随系统：浅色 / 深色（`prefers-color-scheme` 检测）。

## 出问题怎么办？

### 1. 打开签到页看不到右下角悬浮按钮

按以下顺序排查：

1. **脚本管理器里「MT论坛自动签到」是否已启用？** 进 Tampermonkey/Violentmonkey 管理面板确认
2. **Via 浏览器脚本功能是否开启？** 进 Via 设置 → 通用 → 脚本（开关必须打开）
3. **是否登录了 MT 论坛？** 未登录时脚本会尝试执行但拿不到 formhash
4. **打开浏览器控制台查看错误**：
   - 电脑：按 `F12` → Console 标签
   - 移动（Via）：菜单 → 工具箱 → 开发者工具（或远程调试）
   - 应该能看到 `[MT签到] 已就绪, 自动=true, 定时=false, 定时时间=08:00` 这行日志
   - 如果是红色错误，把错误内容截图给我

### 2. 看到按钮但点了没反应

刷新页面（`Ctrl+R` / 移动端下拉刷新）。如果还不行，禁用并重新启用脚本。

### 3. 彻底重装

1. 在脚本管理器里删除旧脚本
2. **同时清掉 localStorage**（控制台执行 `localStorage.clear()`，或 Tampermonkey 面板里清除存储）
3. 重新按安装步骤装一次

## 注意事项

- 脚本 `@grant none`，不申请任何权限，不收集、不上传任何数据，仅在本机浏览器内工作
- 定时签到依赖页面打开：浏览器关闭或未打开论坛页面时不会触发，属用户脚本固有限制
- 若提示「未登录」，请先登录论坛账号
- 签到接口：`plugin.php?id=k_misign:sign&operation=qiandao&formhash=xxx`（Discuz! k_misign「百变每日签到」插件），脚本自动提取 formhash
