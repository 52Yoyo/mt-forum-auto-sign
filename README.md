# MT论坛自动签到（用户脚本）

在 **MT论坛(https://bbs.binmt.cc)** 每日自动签到的浏览器用户脚本。
兼容 **Tampermonkey（篡改猴）**、**Violentmonkey**、**Via 浏览器** 等脚本管理器。

## ✨ 特性

- **全站静默自动签到**：打开论坛任意页面自动完成当日签到，不打扰浏览
- **MD3 悬浮面板**：签到页右下角悬浮按钮 + Material Design 3 卡片式面板，浅色/深色自动跟随系统
- **定时签到**：设置每天固定时间自动签到
- **长按拖动**：悬浮按钮可长按拖到任意位置，一键恢复默认位置
- **签到记录**：最近 8 次签到结果，可查可清空

## 📥 下载安装

前往 **Releases 页面**：<https://github.com/52Yoyo/mt-forum-auto-sign/releases>

点击资产区（Assets）的 **`mt-forum-auto-sign.user.js`**，脚本管理器（Tampermonkey / Violentmonkey / Via）会自动接管弹出安装确认，点「安装」即可。
